# Comedian Reference Library (analysis, not imitation)

These artists are references for **studying technique** (timing, structure,
act-outs, crowd work) so we make better editing decisions. We never
impersonate them, write material "in their style" to pass off as theirs, or
use their names or likenesses to promote the channel.

The notes below are broad, widely known characteristics, here as a starting
point. Before any clip is selected, update each profile from footage you have
actually watched: real bits, real timestamps, and the editing patterns that
worked.

| Comedian | What to study | What it means for the edit |
|---|---|---|
| Gad Elmaleh | Observational bits, character act-outs, cultural contrast (Morocco/France/US) | Keep the full act-out; the face *is* the punchline, so punch in on the character switch |
| Jamel Debbouze | High-energy delivery, fast riffs, crowd interaction | Few cuts, since the rhythm is already fast; captions have to keep up, so short cues |
| Redouane Bougheraba | Crowd work, Marseille identity, improvised exchanges | Show the audience member's line (subtitled) or the reply makes no sense |
| Amine Radi | Short, punchy, relatable situations | Naturally short-form; often 15–25s with minimal edits |
| Jamel Djadel | *To profile from verified footage* | — |
| Kevin Hart | Self-deprecating stories, escalation, big physical reactions | Freeze on the reaction; escalation means keeping the middle beats |
| Dave Chappelle | Long setups, deliberate pauses, layered social commentary | High context risk: often unsuitable for a short. Only clip self-contained bits |
| Gabriel Iglesias | Storytelling, voices and sound effects, warm family humour | His own SFX are part of the joke, so don't add ours on top |
| Trevor Noah | Accents, cross-cultural observation, measured build | Subtitle the accents accurately; let the build breathe |
| Eddie Murphy | Character work, impressions, physical storytelling | Wide framing (`blur_fill`) so the body stays in frame |
| Chris Rock | Rhythmic repetition, emphasis, strong "button" lines | Highlight the repeated word; cut on the rhythm |
| Bernie Mac | Direct address, commanding presence, family themes | Hold on the stare: the silence is the punchline |
| Katt Williams | Rapid-fire delivery, physicality, stage movement | `crop` with care or `blur_fill`; he covers the whole stage |
| Russell Peters | Accent and culture-based crowd work | Crowd lines must be audible or subtitled |
| Jim Carrey | Extreme physical comedy and faces | Visual-first: little text, so leave the face clear |
