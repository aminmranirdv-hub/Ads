# Channel branding: @waitfor.thetwist

**Profile picture to upload:** `profile-picture.png` (800×800, the yellow badge)

| File | Use |
|---|---|
| `profile-picture.png` | Main YouTube profile picture. Yellow stands out in both light and dark mode |
| `badge-black.png`, `badge-red.png` | Alternates for TikTok or Instagram, or for seasonal swaps. The black one blends into YouTube's dark mode, so it isn't recommended as the main picture |
| `badge-preview.jpg` | How each version looks in YouTube's circle crop at 400, 98 and 48 px |

Brand colors (the same as the video overlays): Yellow `#FFDE00` · Red `#E61E28` · Ink `#0F0F0F` · Font: Inter Black (free, OFL)

**How to upload:** YouTube app → Your channel → pencil icon (Edit) → tap the profile picture → choose `profile-picture.png`.
Regenerate with `python3 build_brand.py`.
