# "Tidy Team!": the M'Rani Family Clean Up Song (pilot)
Original lyrics for M'RANI FAMILY. **Ages 1–5.** About 2:30 at a bouncy 112 BPM.
**Musical feel:** happy ukulele-and-xylophone pop with hand claps; a simple 4-chord loop; kids' voices plus a warm big-sister lead.
**Melody note:** the tune must be newly written. Don't base it on any existing clean-up song or nursery rhyme.

## Why it works for toddlers
- **The chorus comes 4 times**, using simple action words (pick up, put back) that kids copy.
- **Counting** (1–3, then 1–5) gives the song learning value, which parents search for.
- **Each verse = one sibling + one object + one sound effect** (swoosh, click, GOAL), so the song teaches and introduces the characters at the same time.
- **The character quirks are kept toddler-safe:** Aziza forgets mid-count, Amir makes everything a goal, Abdel-Hamid yawns, Hicham beep-boops.
- **The ending talks to the viewer** ("Now go clean YOUR room"), which parents love.
